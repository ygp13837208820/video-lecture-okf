# video-lecture-okf

把「一整套讲课视频」变成可交付的**中英对照讲义 + OKF 知识包**（字幕、关键帧、概念文件、校验门一条龙）。

这是一个给 AI 编码助手用的 skill 文档：不是库、不带脚本，只写清流水线每一步**怎么跑、参数是多少、坑在哪**。
基线实例是 **LLE26 On Demand 9 讲**（48 分 53 秒，英→中）：1 份双语对照讲义、9 个 OKF 概念文件（共 12 个 `.md`）、
43 张 1280×720 关键帧、9 讲软/硬字幕。

## 它解决什么

| 环节 | 产出 |
|---|---|
| 取件 | 原片 mp4（走可直下的媒体 CDN，支持 Range 续传） |
| 转写 | faster-whisper 逐字稿 JSON（带术语 `initial_prompt`） |
| 字幕 | 断句合并后的双语 srt + 纯中文 srt + mov_text 软字幕 + 烧录硬字幕 |
| 讲义 | `> **[mm:ss]** 英文原句` + `> 〔中〕中文` 逐段对照 |
| 关键帧 | 按「叙事锚点 + 画面变化 + 事件」打分，分区分段选点，统一 1280×720 |
| OKF 包 | 一概念一文件（`okf_version: "0.2"`）+ index/log + 附录 + assets |
| 校验 | 结构 / 图片链接 / 尺寸分布 / 图注逐字一致 / 字幕流 / 图数一致 |

## 流水线（7 步，每步可单独重跑）

1. **取件** — 搜索或枚举拿 videoId → resolve 拿直链 → 下载；落盘后一律 `ffprobe` 核实真实分辨率。
2. **转写** — `ffmpeg` 抽 16 kHz 单声道 wav → `faster-whisper`（CPU int8，`beam_size=5`，`vad_filter=False`，术语 prompt）。
3. **字幕** — 合并规则（无句末标点 + 间隔 < 1.5 s + 合并后 < 14 s）→ 双语/纯中文 srt（UTF-8 BOM）→ 软字幕、硬字幕。
4. **讲义** — 逐段中英对照排版，按 `## N. 标题` 分节。
5. **关键帧** — 灰度质量门 + 打分选点 + 去重，人工过目后 `crop` 取帧。
6. **OKF 拆分** — 按节切分，frontmatter 键顺序固定（`license` 必须最后一行）。
7. **收尾** — 图注格式统一、讲义与 OKF 两份逐字一致、写取件与转写记录附录。

## 环境（本机已验证）

| 项 | 值 |
|---|---|
| ffmpeg | PATH 里（取帧、混流、烧字幕） |
| Python | 3.10 / 3.11 |
| faster-whisper | 1.2.1（`sys.path.insert` 引入独立目录） |
| ctranslate2 | **必须 4.4.0**（4.8.5 在 Windows 加载模型即崩） |
| 模型 | `medium.en`（1.46 GB） |
| VAD | 装不上 onnxruntime 时只能 `vad_filter=False` |

转写速率：CPU int8 × 4 线程约 **1.6× 实时**（48:53 音频 ≈ 30 min）。

## 最贵的三个坑

1. **图注错配** — 换一套选帧后按「时间相近」复用旧图注，5 处张冠李戴。换图必须重写图注。
2. **ctranslate2 版本崩** — 加载模型瞬间 `0xC0000005`，无栈回溯，锁定 4.4.0 即好。
3. **把质量分当选择分** — Laplacian 方差/曝光/熵只能当门限，计进 score 会选出「清晰但过曝、纯 UI 面板」的帧。

完整 30 条坑表见 `SKILL.md` §2。

## 什么时候不该用

- 单条短视频（< 2 分钟）：固定成本远大于收益。
- 需要自动语义筛选帧：本类素材上 CLIP/分类器实测不可用，人工过目不可省。
- 竖屏/手持素材、无音轨、版权不允许转载的场景。

## 用法

把 `SKILL.md` 放进你的 agent skills 目录（例如 Claude Code / 兼容 harness 的 `skills/video-lecture-okf/SKILL.md`），
在需要「一整套讲课视频 → 讲义 + 知识包」时让 agent 读取它。
